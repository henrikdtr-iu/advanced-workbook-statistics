# Advanced Workbook Statistics

This repository contains the Python calculations and visualizations used for the Advanced Workbook in the module **Further Statistics (DLMDWWS01)**.

The complete source code and corresponding terminal outputs are also included in the appendix of the submitted PDF.

## Contents

- Numerical and symbolic calculations
- Statistical evaluations
- Probability distributions and hypothesis testing
- OLS and Ridge regression
- Bayesian estimation
- Visualizations used in the workbook

## Structure

The Python scripts are organized by workbook task:

- `dlmdwws01_workbook_aufgabe-1.py`
- `dlmdwws01_workbook_aufgabe-2.py`
- `dlmdwws01_workbook_aufgabe-3.py`
- `dlmdwws01_workbook_aufgabe-4.py`
- `dlmdwws01_workbook_aufgabe-5.py`

Only scripts required for the respective calculations are included.

## Requirements

- Python 3.x
- NumPy
- SciPy
- SymPy
- Matplotlib

## How to run

Install the required dependencies:

```bash
pip install numpy scipy sympy matplotlib
```

Run the respective script, for example:

```bash
python dlmdwws01_workbook_aufgabe-5.py
```

The calculations and visualizations are generated directly from the parameters specified in the corresponding workbook task.
